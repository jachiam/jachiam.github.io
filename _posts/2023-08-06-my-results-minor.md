<b>"My Result's Minor"</b><br/>
(to the tune of <a href="https://www.youtube.com/watch?v=qQzdAsjWGPg&ab_channel=FrankSinatra-Topic">"My Way"</a>)

And now, the end is near <br/>
And so I face / the Friday deadline <br/>
I wrote most of what I did <br/>
My advisor / saw it, and said "fine" <br/>

I ran / experiments <br/>
But I know they / should have been finer <br/>
So, woe, oh woe is me, <br/>
My result's minor <br/>

Regret, I bounded you <br/>
So why are you / not sublinear? <br/>
I thought / I understood <br/>
But this proof step / was broken here <br/>

I planned / trajectories <br/>
Each careful torque / with my pathfinder <br/>
But woe, oh woe is me <br/>
My result's minor <br/>

Yes there were times / when I broke through <br/>
And thought I'd done / something brand new <br/>
But then I searched / for it online <br/>
There's a paper / from '89 <br/>
Erase it all / I've hit a wall <br/>
My result's minor <br/>

I've tried, I've cried and cried <br/>
I've had my fill / of doing science <br/>
And now, as my code runs <br/>
My only goal / is sheer defiance <br/>

I swear / I'll make it work <br/>
And I'll publish / this damned meat grinder <br/>
But no, oh no not yet, <br/>
My result's minor <br/>

For what is a grad / what has he got? <br/>
If not strong will / than he has naught <br/>
To heed the call he truly hears <br/>
And not the job of engineer <br/>
The paper shows / I'm one who knows <br/>
My result's minor <br/>

Yes, it was minor <br/>


# Postscript

I wrote this parody for a bit of fun while trying to make the ICML 2017 deadline. It's been gathering dust on my hard drive for a while. I have no particular reason to bring it out now, but I have had "My Way" stuck in my head lately and thought it was worth it to share. If anyone's feeling particularly inspired, I'd be tickled if someone hooked this up to one of the Sinatra voice bots and made it possible to hear Old Blue Eyes sing the academic blues.
